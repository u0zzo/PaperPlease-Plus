# Traveler
#--------------------------------------------------------
# Only put requirements for papers explicitly given
# to the traveler. Day papers aren't considered (Rules, Bulletin, etc)

	\ Passport
	\ FEATURES has SEARCH
	\ FILTER !has ADDITIONAL # don't consider this error if looking for additional errors
	! ~Passport/Gender
		> Interrogate 
			" ask-wrong-gender
			" wrong-gender
			@ Search
